# Implementation Capacity Source Note: Myanmar

This note records source types required for section 5.7.

Core comparative indicators:

- World Bank Worldwide Governance Indicators: `GE.EST`, `RQ.EST`, `CC.EST`.
- World Bank Statistical Performance Indicators: `IQ.SPI.OVRL`.
- World Bank CPIA where available: `IQ.CPA.PADM.XQ`, `IQ.CPA.FINQ.XQ`.
- World Bank WDI public finance and digital indicators: `IT.NET.USER.ZS`, `GC.XPN.COMP.ZS`, `GC.XPN.INTP.RV.ZS`.
- IMF DataMapper fiscal indicators: `rev`, `GGXCNL_NGDP`.
- PEFA budget reliability: `PI-1` from country PEFA assessments when a recent assessment is available.
- World Bank GovTech Maturity Index: use the latest country score/group from the GovTech dataset when it has been archived locally.

Official source checklist:

- Cabinet, presidency, prime minister's office, planning ministry, and finance ministry implementation-monitoring documents.
- Budget execution reports, procurement statistics, audit follow-up reports, and public investment monitoring tables.
- Civil-service workforce statistics, training data, vacancy data, wage-bill information, and performance-management reports.
- Local-government service-delivery statistics and complaint or grievance data.
- Digital-government transaction statistics, interoperability reports, open-data usage, cybersecurity and data-protection documents.

Processed dataset: `MMR/processed/implementation_capacity_diagnostics.csv`.
