# Urbanization and Regional Distribution Source Note: Myanmar

- Urbanization trend: World Bank, World Development Indicators, country code `MMR`, table id `SP.URB.TOTL.IN.ZS`, unit `% of total population`.
- GIS boundary: geoBoundaries ADM1 geometry file `geoboundaries_mmr_adm1.geojson`.
- Regional population: No processed/regional_population_adm1.csv file was found. The section therefore uses ADM1 geometry only and marks official regional population values for national statistical office collection.
- Editorial rule: do not estimate ADM1 population from polygon area or visual size. Use the latest official national statistical office table for current regional population and calculate the five-year change rate from the same official series whenever possible.
