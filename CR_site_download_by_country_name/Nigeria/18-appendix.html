18.5 Update Workflow and Evidence Archive

Annual updates should run `python NGA\code\fetch_data.py`, verify raw files in `NGA/raw`, rebuild pages with `python NGA\code\build_report.py`, archive official and diagnostic documents with `python NGA\code\download_sources.py`, and then run `python tools\sectionize_reports.py`. New sources should be added to `SOURCE_LINKS`, the APA reference list, and `NGA/sources/source_register.csv`.

The categorized statistical appendix is incorporated as Section 18.6 below. Its generated output preserves the input run, chart manifest, summary table, and source limitations.

18.6 Statistical Country Profile

The interactive Nigeria in Comparative Statistics appendix organizes internationally comparable indicators by analytical domain and shows Nigeria alongside a fixed peer group. Trend charts distinguish countries by both color and line pattern, and hovering over a figure reveals the underlying values.

The appendix is descriptive rather than causal. Differences in definitions, reporting periods, modeled estimates, and country coverage must be checked in the source and validation notes before an indicator is used to support a substantive claim. Indicators for which Nigeria has no observation are recorded as unavailable rather than treated as zero.
