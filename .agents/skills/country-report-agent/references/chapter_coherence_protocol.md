# Chapter Coherence Protocol

Use this protocol before rewriting several sections in one chapter and before assigning `deep draft` or `publication candidate` status. A section can be strong in isolation while the chapter remains repetitive, discontinuous, or analytically incoherent.

## 1. State the chapter's governing question

Write one question that the chapter as a whole answers. Then give each section a distinct role: define the institutional setting, explain historical formation, test a proposition, trace a mechanism, compare jurisdictions, examine implementation, or synthesize implications. Do not give every section the same internal checklist.

## 2. Choose a section-specific narrative pattern

Select the order that fits the material rather than a universal sequence.

- Historical-institutional: turning point -> institutional settlement -> path dependence -> later consequences.
- Statistical-diagnostic: empirical puzzle -> trend/comparison/distribution -> competing explanation -> bounded inference.
- Legal-constitutional: formal rule -> allocation of authority -> practice or litigation -> implementation gap.
- Policy-process: problem framing -> coalition and instruments -> implementation mechanism -> feedback and failure conditions.
- Comparative: common benchmark -> case divergence -> mechanism -> scope condition.
- Synthetic: cross-section finding -> tension or trade-off -> operating model -> unresolved question.

These are optional patterns, not visible headings. Combine, invert, or omit elements when the chapter's logic requires it.

## 3. Build the chapter evidence map

For each section record the central claim, indispensable evidence, evidence type, and contribution to the chapter question. Check that adjacent sections do not reuse the same statistic, quotation, historical episode, or conclusion unless the second use changes its analytical function.

## 4. Audit transitions and accumulation

Read the first and last paragraph of every section in sequence. Confirm that:

- the end of one section creates a substantive reason for the next;
- later sections build on, qualify, or contest earlier findings;
- key concepts retain the same meaning;
- repeated background is replaced by a cross-reference;
- the chapter conclusion answers the governing question rather than summarizing every section mechanically.

## 5. Check disagreement and causal scope

Where evidence conflicts, state the competing interpretation and why the chapter adopts or withholds judgment. Separate descriptive patterns, mechanism evidence, and causal identification. Do not infer an institutional effect solely from temporal coincidence or a cross-country ranking.

## 6. Manual review record

Before publication, record:

- chapter question and one-sentence answer;
- distinct role of each section;
- repeated evidence removed or justified;
- unresolved contradiction or limitation;
- whether the section order should change;
- editor/reviewer and review date.

Automated audits can identify repeated language and missing registered evidence, but they cannot certify chapter logic. Manual chapter review is mandatory.
