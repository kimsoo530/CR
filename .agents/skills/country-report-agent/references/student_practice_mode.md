# Student Practice Mode

Use this reference when preparing lessons, assignments, rubrics, or classroom workflows. For ready-to-use Codex prompt examples, also read `prompt_templates.md`. For student feedback tables, read `output_templates.md`.

## Teaching Goal

Teach students to use Codex as a controlled research and editing partner, not as a black-box writer. The core learning outcome is the ability to trace a country-report claim through evidence, source type, statistical support, and interpretation.

## Recommended Student Outputs

- Target country, chapter, and section file
- One-sentence central thesis for the section
- Claim-evidence-source table
- A Codex prompt using Goal, Context, Constraints, Actions, and Done when
- Top three revision priorities
- Short note on what a human must still verify

## Basic Exercise

1. Assign one country folder.
2. Have students inspect `raw`, `processed`, `sources`, `report`, and `sources/sections`.
3. Choose one section from chapter 5, 7, 16, or 17.
4. Identify the section's main claim.
5. Mark which claims need official documents, national statistics, international indicators, diagnostics, or academic sources.

## Advanced Exercise

1. Read a quality-audit file when available.
2. Create a source-gap table.
3. Rewrite one paragraph while preserving country-specific content.
4. Check numerical claims.
5. Decide whether the section is first-pass, deep draft, or publication-candidate quality.

## Evaluation Rubric

- Country specificity: named institutions, laws, reforms, or regions are present.
- Evidence mapping: official, national-statistical, international, diagnostic, and academic sources are distinguished.
- Numerical precision: values, years, units, and source IDs are included.
- Interpretation: evidence is linked to state capacity, implementation, risk, or policy strategy.
- Prompt quality: Codex request has clear goal, context, constraints, actions, and done condition.
- Editorial judgment: students identify what Codex can do and what humans must verify.
